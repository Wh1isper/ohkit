# Security Policy

## Supported Versions

During pre-alpha development, security fixes target the latest released version and `main`. Older pre-alpha versions have no backport guarantee.

## Reporting a Vulnerability

Report suspected vulnerabilities privately to [jizhongsheng957@gmail.com](mailto:jizhongsheng957@gmail.com) with the subject "ohkit security report". Do not post credentials, private transcripts, or exploitable vulnerability details in public Issues. Include affected versions, reproduction steps, impact, and a minimal redacted example.

Never commit provider credentials or PyPI tokens. Publication credentials belong in the protected GitHub Actions Environment described in [releasing](docs/releasing.md).
