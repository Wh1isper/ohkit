# ohkit Specifications

ohkit is an independent Python library for a unified coding-agent API. It does not depend on Agent Foundation, Harness, or Pydantic AI. The initial package establishes engineering and publication boundaries only; agent backends and a public execution API are not implemented.

This directory records accepted contracts, not proposals or progress reports.

- [Repository Model](repository-model.md): surfaces, package ownership, and release boundaries.
- [Data Conventions](data-conventions.md): naming and data authority.
- [API Conventions](api-conventions.md): public-surface and compatibility boundaries.
